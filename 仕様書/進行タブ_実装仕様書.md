# DSDsp 進行タブ 実装仕様書

作成日: 2025-07-17  
対象リポジトリ: `DScore/DSDsp`

---

## 1. 概要

「進行タブ」は競技会の進行（区分・ラウンド）を順番に画面表示するための機能。  
DS_Status から進行一覧を動的に生成し、再生ボタンを押すたびに画面のステップを進める。

AJS タブとの主な違い：

| 項目 | AJS タブ | 進行タブ |
|---|---|---|
| 画面 | DSP_TIT/SOL/GRP/DUE_xxx | DSP_PRG_001〜007 |
| データソース | DV_Result（採点結果） | DS_Status（進行状況） |
| 進行一覧 | シナリオ JSON ファイルから生成 | DS_Status から動的生成 |
| 切り替え粒度 | 1種目・1ヒートごと | 1区分・1ラウンドごと |

## 3. 画面 ID の選択ロジック

大/小 × モードの組み合わせで使用する画面 ID が決まる。

```csharp
// MainWindow.cs: GetProgressScreenId()
bool isSmall = (_progressSize == ProgressSize.Small);
return _progressMode switch
{
    ProgressDisplayMode.Heat  when !isSmall => "DSP_PRG_004",
    ProgressDisplayMode.Heat  when isSmall  => "DSP_PRG_005",
    ProgressDisplayMode.Final when !isSmall => "DSP_PRG_006",
    ProgressDisplayMode.Final when isSmall  => "DSP_PRG_007",
    _ when !isSmall => "DSP_PRG_001",
    _               => "DSP_PRG_002",
};
```

| モード | 大 | 小 |
|---|---|---|
| 進行のみ | DSP_PRG_001 | DSP_PRG_002 |
| ヒートも | DSP_PRG_004 | DSP_PRG_005 |
| 決勝 | DSP_PRG_006 | DSP_PRG_007 |

> 2フロアの場合は将来的に DSP_PRG_003 固定とする予定（現時点では未実装）。

## 4. 進行一覧の構築

「📋 進行一覧を更新」ボタンを押すと `LoadProgressList()` が呼ばれる。

```
DS_Status["DS_FLOORs"]
    └─ 各 Floor の DS_PRGRSs を DS_SortOrder 昇順で列挙
        └─ 各 PRGRS エントリ
              DS_PrgNo   → PrgNo
              DS_KbnNo   → KbnNo
              DS_RndNo   → RndNo
              DA_Master から区分名・ラウンド名を解決
```

ListBox の表示テキスト例：
```
001  Ａ級戦スタンダード　１次予選
002  Ａ級戦スタンダード　決勝
003  Ｂ級戦ラテン　１次予選
```

> DA_Master が未取得の場合は区分番号・ラウンド番号をそのまま表示する。  
> DS_Status が未取得の場合は「（DS_Status 未受信）」を表示する。

## 5. 再生フロー

```
[▶ 再生] ボタン
    │
    ▼
ExecuteCurrentStep()  ← TabControl.SelectedIndex == 0 のとき
    │
    ▼
ExecuteProgressStep()
    │
    ├─ 選択中の ProgressListItem を取得
    ├─ GetProgressScreenId() で画面ID を決定
    │
    ├─ 画面が変わる場合（初回 / 画面ID変更 / 区分・ラウンド変更）
    │       └─ CreateProgressScreen() → ShowScreen() → 新画面表示
    │
    └─ Advance() を呼ぶ（= 現在ステップ実行 → _currentStep++）
```

### 画面の切り替え判定

以下のいずれかに変化があった場合に新画面を生成する：

- `_currentProgressScreenId != screenId`（モード・大小切り替え）
- `_currentProgressScreen.区分番号 != item.KbnNo`
- `_currentProgressScreen.ラウンド番号 != item.RndNo`

同一区分・ラウンドのまま再生を続ける場合は既存の画面に `Advance()` を送るだけなので、
DSP_PRG_004 のように「STEP3 → STEP4 → STEP3 → …（ヒート毎更新）」の内部ループも自然に動作する。

### ScreenCompleted 後の自動遷移

```csharp
// OnProgressScreenCompleted()
int nextIdx = _currentProgressIndex + 1;
if (nextIdx < _progressList.Count)
{
    _currentProgressIndex = nextIdx;
    LstProgressItems.SelectedIndex = nextIdx;   // 次の進行に選択を移動
}
```

`ScreenCompleted` が発火（全ステップ完了）すると `LstProgressItems` の選択が自動的に次の進行に移る。  
オペレーターはそのまま再生ボタンを押せば次の進行の STEP1 から始まる。

## 6. DSP_PRG_004 進行表示ヒート表_大 のステップ仕様

### 6.1 ステップ構成

| ステップ | 名称 | 処理 |
|---|---|---|
| STEP1（case 0） | 共通ヘッダ表示 | COM001（競技会名）・COM002（現在時刻）を表示。ヒートデータを事前計算。 |
| STEP2（case 1） | タイトル・次進行表示 | LB_タイトル1/2・LB_種目・LB_次・LB_次_明細・LB_次_時刻 を表示 |
| STEP3（case 2〜） | ヒート表示 | 一括 or ヒート毎にヒート行を表示 |
| STEP4 | ヒート非表示 | STEP3 で表示した行を非表示 |
| STEP5 | タイトル非表示 → 完了 | STEP2 で表示した要素を非表示 → `RaiseScreenCompleted()` |

### 6.2 表示モードの判定

```
ヒートシャッフルあり（種目によって選手配置が異なる）
    → ヒート毎更新モード: 種目×ヒートを全列挙
    
シャッフルなし かつ ヒート数 ≦ 8
    → 一括表示モード: 全ヒートを 1〜8 行に一度に表示（STEP3 は1回のみ）
    
シャッフルなし かつ ヒート数 > 8
    → ヒート毎更新モード: 代表種目のヒートを順に列挙
```

### 6.3 LB_ヒート の表示形式

| モード | 表示例 |
|---|---|
| 一括表示 | `1H`、`2H`、`3H`（ヒート番号のみ） |
| ヒート毎更新 | `W 1H`、`Q 10H`（種目記号 + ヒート番号） |

### 6.4 LB_背番号 の色

| 状態 | 色 |
|---|---|
| 現在種目 かつ 現在ヒート | 濃いオレンジ `RGB(204, 85, 0)` |
| それ以外 | ダークブルー `RGB(0, 0, 139)` |

### 6.5 LB_種目 の色（TextBlock + Run で個別着色）

| 状態 | 色 |
|---|---|
| 現在種目 | 濃いオレンジ `RGB(204, 85, 0)` |
| それ以外 | 白 `White` |

> **実装メモ**: `LB_種目` は XAML で `Label` ではなく `TextBlock` として定義し、  
> `UpdateLB種目()` 内で `TextBlock.Inlines` に `Run` を追加することで種目ごとに色を変えている。  
> `Label.Foreground` は単一色のみのため、この方式が必要。

### 6.6 LB_次_時刻 の表示条件

DS_Status の `DS_PrgPStaTM` が取得できる場合のみ表示。データなし = ラベル非表示。

```
表示例: 「開始予定　11:50」
非表示: DS_PrgPStaTM が空または null の場合
```

## 7. 割り込みメッセージ（DSP_MSG_001）

「インターバル」「調整中」「任意メッセージ」ボタンで DSP_MSG_001 を即時表示する。  
現在の画面はそのまま残り、MSG 画面が上に重なって表示される。

```csharp
// ShowInterruptMessage()
var msgScreen = new DSP_MSG_001_メッセージ { MessageType = msgType, ... };
_offScreenWindow.ShowScreen(msgScreen, "DSP_MSG_001");
msgScreen.Advance();   // STEP1: メッセージパネル表示
```

MSG 画面のステップは2ステップのみ：

| ステップ | 処理 |
|---|---|
| STEP1 | メッセージパネルを表示 |
| STEP2 | パネルを非表示 → `RaiseScreenCompleted()` |

> 現在の実装では割り込み後に元の進行画面へ自動復帰しない。  
> 割り込みを終了したい場合は再度 STEP2 の Advance() を手動で送るか、  
> 進行タブの次の進行を再生することで上書きする。

### メッセージタイプ

| タイプ定数 | 表示内容 |
|---|---|
| `TYPE_INTERVAL` = `"Interval"` | 「インターバル」 |
| `TYPE_ADJUSTING` = `"Adjusting"` | 「調整中」 / 「お待ちください」（2行） |
| `TYPE_CUSTOM` = `"Custom"` | `Message` プロパティの文字列 |

`\n` または実際の改行で2行に分割可能。

## 9. 内部モデル

### ProgressListItem（MainWindow.xaml.cs 内部クラス）

```csharp
private class ProgressListItem
{
    public string PrgNo   { get; set; }   // DS_PrgNo  例: "001"
    public string KbnNo   { get; set; }   // DS_KbnNo  例: "01"
    public string RndNo   { get; set; }   // DS_RndNo  例: "010"
    public string KbnName { get; set; }   // DA_Master から解決した区分名
    public string RndName { get; set; }   // DA_Master から解決したラウンド名
    // ToString(): "001  Ａ級戦スタンダード　１次予選"
}
```

### ProgressDisplayMode / ProgressSize 列挙

```csharp
private enum ProgressDisplayMode { ProgressOnly, Heat, Final }
```
